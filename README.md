# loan-prediction-project
Loan Default Prediction Using Machine Learning

## Project Overview
This project focuses on analysing customer credit-card information to identify patterns and factors that contribute to loan repayment defaults and developing a machine learning model that can predict whether a customer is likely to default on their payment in the following month.
The project uses historical customer data, including demographic information, credit limits, repayment history, bill statements, and previous payment amounts.

The goal is to build a predictive model that can help financial institutions improve credit risk assessment, make better lending decisions, and identify customers who may be at risk of defaulting.

## Problem Statement

Loan and credit-card defaults pose financial risks to banks and other financial institutions. When customers fail to meet their repayment obligations, financial institutions experience losses.

## Dataset Description

**Dataset:** Default of Credit Card Clients

**Source:** UCI Machine Learning Repository

**Country:** Taiwan

**Dataset Size:** 30,000 customer records and 25 columns.

The dataset contains customer demographic information, credit limits, repayment status over six months, bill statement amounts, payment amounts, and the target variable.

### Main Dataset Features

- Customer information: ID, gender, education, marital status, and age.
- Credit information: Credit limit.
- Repayment history: Repayment status from April to September.
- Bill statements: Monthly bill amounts.
- Previous payments: Monthly payment amounts.
- Target variable: Whether the customer defaults on payment in the following month.

**Target Variable:** `DEFAULT_NEXT_MONTH`

- 0 = No default
- 1 = Default
Traditional credit assessment methods may not always identify customers who are likely to default.

This project explores how data analysis and machine learning can be used to identify important factors associated with customer defaults and predict potential defaults using historical financial data.
